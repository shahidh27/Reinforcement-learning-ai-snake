# 🐍 Reinforcement Learning AI Snake
An AI-powered Snake game built using **Python, Q-Learning, and Reinforcement Learning**.

## 🤖 How It Works
The AI learns to play Snake through **trial and error** using rewards and penalties.
- 🍎 Eating food → Positive reward
- 💥 Collision → Negative reward
- ➡️ Moving closer to food → Small reward

The AI uses a **Q-table** to learn better actions over time.

## 🛠️ Technologies
- Python
- Tkinter
- Q-Learning
- Reinforcement Learning

## ✨ Features
- Automatic AI gameplay
- Q-Learning based decision making
- Automatic training
- Score tracking
- Saves learned knowledge

## ▶️ How to Run
1. Install Python 3.
2. Open `RL_snakegame.py`.
3. Run the program.
4. The AI trains and then plays Snake automatically.

## 🎯 Goal
To demonstrate how an AI agent can learn to play a game using **Reinforcement Learning**.
